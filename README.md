## ✨ 1st Semester Web Development Phase: The First Steps

During the **first semester** of a Web Development course, learning focuses heavily on mastering the foundations of the web before moving to complex programming and backend architectures.

### Step 1: The Building Blocks (HTML & CSS)
The primary goal in the first semester is understanding **Structure** and **Presentation**:

1. **Semantic HTML5:** Using the correct, meaningful tags (`<header>`, `<nav>`, `<section>`, `<footer>`) instead of throwing everything inside generic `<div>` tags. This makes the code self-documenting and accessible.
2. **CSS Basics:** Understanding the Box Model (Margin, Border, Padding, Content) and how elements interact on the page.
3. **Layout Techniques:** Moving away from outdated float-based layouts and adopting modern tools like **CSS Flexbox** and **CSS Grid** to align items cleanly (e.g., our `.grid-container` and `.navbar`!).
4. **Modularity & File Structure:** Separating concerns. Keeping HTML purely for content, moving CSS styling into a dedicated `css/` directory, and distributing separate subpages into a `pages/` directory to ensure the project remains scalable and organized.

This project is a perfect practical example of these 1st Semester goals: readable semantic HTML, clean separation of CSS, and an organized, professional directory structure.
